# Requerimiento inicial

Agregar inicio de sesión con Google.

## Información deliberadamente ausente

Este ejemplo es incompleto para demostrar cómo SuckLess detecta vacíos y entrevista al responsable.

El agente debería preguntar, entre otras cosas:

- Si Google reemplaza o complementa el inicio de sesión actual.
- Qué ocurre si el correo ya está registrado.
- Qué datos del perfil se almacenan.
- Qué ocurre si el usuario cancela la autorización.
